Derive once, serialize everywhere

Define your type, add the formats you need, and you're done. The same annotation vocabulary works across every backend.

data Person = Person { name :: !Text, age :: !Int }
  deriving stock (Show, Eq, Generic)
  deriving anyclass (ToMsgPack, FromMsgPack, ToCBOR, FromCBOR, ToYAML, FromYAML)

Generate types from any schema language

Point wireform-gen at a schema file and get idiomatic Haskell — or use a Template Haskell splice and skip the CLI entirely.

-- No protoc binary needed. No generated files to commit.
$(loadProto "proto/person.proto")

-- Or use the CLI for any of 10 schema languages.
-- $ wireform-gen proto  -i api.proto     -o gen/
-- $ wireform-gen avro   -i user.avsc     -o gen/
-- $ wireform-gen thrift -i service.thrift -o gen/

Real XML and HTML processing

A fast XML parser with XPath and XSLT. A fully spec-compliant HTML5 tree builder with CSS selectors and a streaming rewriter.

-- CSS selectors on parsed HTML, just like the browser
let articles = querySelectorAll "article.post > h2" document

-- XPath queries on XML
let titles = query "//book/title" catalog

Analytics without the JVM

Read and write Parquet, Arrow, and ORC files. Query Iceberg tables through REST, Glue, or Hadoop catalogs. No Spark required.

rows <- readParquet "events.parquet"
  & filterPredicate (col "status" .== lit "active")
  & selectColumns ["user_id", "event_type", "timestamp"]

Kafka and gRPC, built in

A full Kafka client with producers, consumers, transactions, and a Streams DSL. A native gRPC implementation with bidirectional streaming.

produce producer "events" (avroEncode event)

withTransaction consumer $ \records ->
  for_ records processEvent
