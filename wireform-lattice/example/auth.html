Lattice — auth slices compose

One query, three visibility slices. Emission is slice-exact, so pub, ctx, and priv return disjoint field sets that the client merges by (id, ver). Pick an identity and watch which fields each slice contributes — the gates are predicates over your claims, so the same cache partition shows different callers different data.
